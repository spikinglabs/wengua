# CLI

Comes with both packages.

```bash
wengua cast --method yarrow --question "What should I understand about this move?"
wengua cast --json            # machine-readable output for coding agents
wengua lookup 乾
wengua read 7,8,9,6,7,8       # a physical cast, bottom line first
```
