# 问卦 Wengua：设计

状态：待审草案 · 2026-11-22

问卦让人们可以在任何 AI 助手或智能体里问《易经》（《周易》）。起卦和取辞由程序完成，模型只负责解读。（排卦归程序，解卦归模型。）

本文说明问卦的宗旨、各部分如何运作，以及开发顺序。

---

## 1. 定位

> **问卦 Wengua：为所有 AI 打造的准确、开放的《易经》工具。**
> 可靠的中文原文、忠实的英译，以及中英两种语言的现代白话注释。起卦公平、可以验证。在 Claude、ChatGPT、Codex、Cursor 和任何 MCP 客户端中都能用，装不装东西都行。

原则：

- **程序起卦，模型读卦。** 所有随机过程、卦与卦的关系和取辞都由程序完成，并附带可审计的元数据返回。模型绝不编造卦象或爻辞。
- **来源优先。** 每段文字都注明来源、版本和异文。
- **重在反思，不做预言。** 技能把占卦定位为反思。它不对医疗、法律和财务问题下结论，也绝不声称有超自然的准确性。
- **默认双语。** 中文为正本，回答的语言跟随用户。
- **运行免费。** 没有账号，服务端不调用大模型。托管接口无状态，成本很低。

## 2. 功能设计

### 2.1 数据集（`data/`），单独发布为 `wengua-data`

每卦一个 JSON 文件，另有 `trigrams.json`。它们会合并生成一个 `iching.json`，按 SemVer 标注版本。

每卦包括：

- `number`（文王序）、`unicode`（䷀ U+4DC0…）、`binary`（自下而上，`"111111"`）、上下卦 `upper` / `lower`
- `name`：`{ zh_hant: "乾", zh_hans: "乾", pinyin: "qián", en: "The Creative / Force" }`
- `judgment`（卦辞）、`tuan`（彖传）、`image`（大象）、`wenyan`（文言，仅乾、坤）
- `lines[1..6]`：`{ position, label: "初九", text（爻辞）, xiao_xiang（小象） }`。第 1、2 卦另有 `use_nine` / `use_six`（用九 / 用六）。
- 每段文字都有 `zh_hant`、`zh_hans`、`en_legge`、`zh_plain`（我们的白话）、`en_plain`（我们的浅白英文）和 `source`（`{ edition, ref, variants[] }`）。

来源：
- 中文：以武英殿本《周易正义》为基础的通行本，与四部丛刊本和维基文库对校。公有领域。
- 英文：理雅各（James Legge），*The Yi King*（《东方圣书》第十六卷，1882）。公有领域。
- `zh_plain` 与 `en_plain`：由我们撰写并经人工审阅，随数据集以 CC BY-SA 4.0 发布。
- **不使用：** 任何仍受版权保护的现代译本或注释。

许可：数据集采用 CC BY-SA 4.0，因为我们依据的数字转录要求相同方式共享。经文本身属于公有领域。代码采用 MIT。

校验（在 CI 中）：64 卦、384 爻加用九/用六；二进制、卦序、Unicode 相互一致；每个爻题（九/六，初…上）与其阴阳相符；简体文本与繁体文本经 OpenCC 转换的结果一致（附审阅过的例外清单）；没有空字段。

### 2.2 核心库（`wengua-core`，TypeScript 与 Python）

用两种语言实现同一套逻辑，并用**同一份测试向量**验证，使两种实现不会各走各的。

- **起卦方法**
  - `coins`：三枚铜钱，P(6, 7, 8, 9) = 1/8, 3/8, 3/8, 1/8。记录每一次掷钱。
  - `yarrow`：大衍筮法，P(6, 7, 8, 9) = 1/16, 5/16, 7/16, 3/16。模拟真实的分策过程，而不只是最终概率，因此每一步都可以重现。
  - `manual`：用户输入实物起卦得到的六个数（6/7/8/9，自下而上），或铜钱的正反。
  - 以后：`meihua`（以时间或数字起卦的梅花易数），并清楚标明属于另一派。
- **随机数**：安全随机数生成器（`crypto.getRandomValues` / `secrets`）。只有调用方设定 `mode: "test"` 时才允许 `seed`，并在输出中注明。CI 用卡方检验检查分布。
- **推演**：本卦、动爻、之卦、互卦、错卦、综卦。
- **取辞**：默认按朱熹《易学启蒙》依变爻数（0 到 6，含用九/用六）取辞的规则。其他做法须主动选择并有名称，让模型知道自己用的是哪一派。
- **查卦**：可按卦序、中文卦名（繁或简）、带或不带声调的拼音、英文名、Unicode 卦符、二进制或上下卦组合（“坎上震下”）查找。
- **输出**：一个 `Reading` 对象，包含 `primary`、`changing_lines`、`relating`、`nuclear`、`selected_texts`、`method`、`audit`（{随机数来源、每枚铜钱或每次分策的记录、时间戳、程序库和数据集版本}）以及 `locale`。

### 2.3 集成：都是核心之上的薄层

| 形式 | 包 | 面向 | 说明 |
|---|---|---|---|
| Agent Skill | `skills/wengua/` | Claude、ChatGPT、Codex、Cursor、Copilot（70 多个平台） | 一个 `SKILL.md` 加上内置脚本和数据，不需要服务器。它教会模型读卦的流程（§2.4）。 |
| 本地 MCP | `npx wengua` / `uvx wengua` | Claude 桌面版与 Claude Code、Cursor、VS Code、Goose | stdio。支持 MCP 2026-07-28（无状态）及更早的版本。 |
| 远程 MCP | `https://mcp.wengua.<domain>/mcp` | 无法安装任何东西的 Claude.ai、ChatGPT 和手机用户 | Cloudflare Workers，无状态，无需认证，按 IP 限流，不记录问题。 |
| MCP App | `ui://wengua/reading/<hash>` | Claude 和 ChatGPT（两者都支持 MCP Apps） | 内嵌卡片，画出本卦 → 之卦，突出变爻，可切换中/英和繁/简，并可选铜钱或分策的回放动画。 |
| 命令行 | `wengua cast --json` | 编程智能体、终端用户 | 随包附带。 |
| 数据与文档 | `wengua-data`、`llms.txt`、静态网站 | 想自己做工具的人 | npm 和 PyPI 上的数据集，加上收录全部六十四卦的双语静态网站。 |
| 目录上架 | MCP Registry、Claude 连接器、ChatGPT 插件、Smithery | 让人发现 | — |

MCP 工具（保持少而贴合任务）：

| 工具 | 输入 | 返回 |
|---|---|---|
| `cast` | `question`（可选但鼓励填写）、`method`（coins/yarrow）、`locale` | 一个 `Reading`，支持时附 MCP App 卡片 |
| `read_cast` | 实物起卦的六个爻值或铜钱正反、`question` | 一个 `Reading` |
| `lookup` | 任何标识（卦序、卦名、拼音、䷀、二进制、上下卦） | 该卦及其全部文字层 |
| `relations` | 卦，可选变爻 | 之/互/错/综及其文字 |

资源：`wengua://hexagram/{n}`、`wengua://trigram/{name}`。提示词：`reading`，引导式占卦模板。

### 2.4 读卦之道（技能与提示词）

1. 帮用户把模糊的担忧整理成一个清楚、开放的问题（例如“关于……我应当明白什么”，而不是是非题）。
2. 调用 `cast`（实物起卦则用 `read_cast`）。**绝不编造或“重起”结果。** 建议不要很快就同一问题再起一卦（不再三），但第一版不强制。
3. 呈现卦象：卦符、中英卦名、爻画和变爻。
4. 引用选出的中文原文并附翻译，说明是哪条规则选出的。
5. 把文字和意象与用户的处境联系起来解读。把经文与我们的解读清楚分开。
6. 以一两个引人反思的问题结尾，而不是下定论。
7. 界限：不对医疗、法律或财务问题下结论，不预测第三方，发现用户陷入困扰时，指引对方寻求真正的帮助。

### 2.5 质量与可信

- CI 中有共用测试向量（TS ↔ Python）、数据校验和随机数分布检验。
- 一套**智能体评测集**：约 30 段脚本对话，检查模型是否调用工具、是否编造文字、是否引用正确的爻、是否用用户的语言回答、是否守住界限。每次发布前在 Claude 和 GPT 模型上运行。
- `SOURCES.md` 记录版本、异文和每一项编辑取舍。
- 隐私：托管服务从不保存问题；日志只保留计数。

## 3. 开发顺序

| 里程碑 | 范围 | 完成标准 |
|---|---|---|
| **M0 数据集** | 64 卦 × 全部经传 + 理雅各英译；`SOURCES.md`；校验程序 | CI 检查通过，并人工抽查 10 卦 |
| **M1 核心库** | TS + Python 核心、共用测试向量、随机数检验 | 两种实现通过同一套测试向量 |
| **M2 技能 + 本地 MCP + 命令行** | `skills/wengua`、`npx wengua`、`uvx wengua`、`wengua` 命令行 | 在 Claude Code、Claude 桌面版、Codex 和 Cursor 中可用；评测集 v1 通过 |
| **M3 远程 MCP + MCP App** | Cloudflare Worker、卦象卡片 | 在 Claude.ai 和 ChatGPT 中贴上网址即可用 |
| **M4 白话注释** | 64 卦 + 386 爻的 `zh_plain` / `en_plain` | 经人工审阅 |
| **M5 发布** | 发布到 npm/PyPI、MCP Registry、Claude 目录、ChatGPT 插件，静态网站 + `llms.txt` | 已上架、可安装 |
| 以后 | 梅花易数、可选的纯本地占卦记录、更多语言（日本語、한국어） | — |

M4 可以与 M1 到 M3 同时进行。没有白话注释工具也能用，只是不返回这些字段。
